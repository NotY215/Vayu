# Governance

Vayu is maintained by **NotY215 (Shreyas Mishra)**.

The maintainer controls language design, compiler architecture, releases, licensing, and final merge decisions. Technical changes should preserve the documented Vayu frontend, VIB / Integrator boundaries, runtime contracts, and testable language semantics.

Contributors are welcome through issues and pull requests. Major language, IR, ABI, cache-format, or runtime changes should include an architecture note, documentation, and tests.
