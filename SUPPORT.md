# Support

Vayu is a Python-inspired programming language and native compiler ecosystem. The current native path uses VCBIR and VCB for x86-64 PE/ELF output.

Read the documentation under docs/ before opening an issue. For compiler bugs, include the Vayu version/commit, source snippet, target/backend, command and exact diagnostic.

For VCB backend issues, include the relevant .vcbir or backend command when safe.
