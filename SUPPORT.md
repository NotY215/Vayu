# Support

Vayu is an independent programming-language project with a C++ frontend, interpreter, bytecode/VM, runtime integrations, and developer tooling. The native compiler is being rebuilt as VIB (Vayu Integration Backend) under the Integrator architecture.

Read [the documentation map](Documentation.md) and [the roadmap](Roadmap.md) before opening an issue. For compiler bugs, include the Vayu commit, source snippet, execution mode (`--run`, `--vm`, or `--native`), command, platform, and exact diagnostic.

For native-mode reports during the VIB transition, include whether the issue occurs before or after the native backend's current “not implemented” diagnostic. Do not attach secrets, tokens, or proprietary source code.
